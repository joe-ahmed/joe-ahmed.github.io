What I’ve built

Farahi — Wedding Services Booking Platform

Graduation project, Sohag University, 2026

A web marketplace for Sohag where couples browse, compare and book wedding halls and services, providers manage their listings and bookings from a dashboard, and admins approve new services before they go live.

  • C#
  • ASP.NET Core 8
  • SQL Server
  • React
  • xUnit

The backend is a REST API with JWT authentication, role-based access for customers, providers and admins, and 40+ endpoints covering services, bookings, payments, reviews and notifications. The database is 17 tables in SQL Server with versioned migration scripts, and the API is covered by 45 integration tests.

My part

  • Wrote the full analysis and design documentation: requirements, context diagram, data-flow diagram, use-case scenarios, entity-relationship diagram and the UI/UX chapter.
  • Was the team’s point of contact with our three supervisors, turning their feedback into the design and delivering what they asked for at the final review.
  • Defined the requirements and screens, reviewed the code, ran the API, database and frontend locally, and tested every feature until it worked as intended.
